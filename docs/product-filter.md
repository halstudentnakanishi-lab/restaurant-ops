# 追加機能：商品名による絞り込み

この変更はCodexが実装しました。応募者が独力で追加した機能とは表記せず、以下を手元で確認しながら学習してください。

## 操作

ダッシュボードの「商品名」に「コーヒー」と入力して適用すると、その文字列を含む商品の売上だけを集計します。
期間と商品名はAND条件です。合計、日別グラフ、商品別一覧、CSV出力のすべてが同じ条件になります。
「条件をリセット」で全件に戻ります。日報は店舗の1日全体を記録するため、検索条件は引き継ぎません。

## 画面からDBまで

1. `static/index.html` の `product-filter` が入力欄。
2. `static/app.js` が `URLSearchParams` でAPIの `product` パラメータを組み立てる。
3. `app/main.py` で最大100文字に制限する。
4. `app/service.py` の `summary` が `instr(product, ?) > 0` をSQLへ追加する。
5. 同じ条件で合計・日別・商品別を取得し、画面へ返す。

SQLへ文字列を直接連結せず、`?` と引数を分けています。`%` や `_` はワイルドカードにせず、入力された文字そのものを探します。
前後の空白は除去します。英字の大小、全角半角、ひらがなとカタカナは区別します。

## 手元で試す課題

- サンプルで「コーヒー」を検索し、162点・72,900円になるか確認する。
- 「2026-10-01」のみにすると18点・8,100円になるか確認する。
- CSV出力も同じ値になるか確認する。
- 存在しない商品名を入れ、0件の案内を確認する。
- リセットして574点・383,340円に戻るか確認する。

## 次に自分で変更するなら

英字の大文字・小文字を区別しない検索や、商品候補の選択を追加してみてください。
変更前に期待する挙動を決め、テストを書き、変更箇所を説明できるようにします。
