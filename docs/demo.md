# デモ・応募での見せ方

## 2〜3分の説明例

### 0:00 課題

「飲食店の閉店後に行う売上集計と日報への転記を想定し、CSVから確認・集計・日報作成をまとめるデモを作りました。」

### 0:20 取り込み

サンプルを取り込み、35行が保存されたことを示す。
ダッシュボードで合計と商品別売上を見せ、期間を変える。

### 0:55 例外処理

同じサンプルを再度取り込み、重複が拒否されることを見せる。
異常サンプルでは、誤った日付・数量が行番号付きで表示される。
「失敗しても途中の行だけ残ることがないようにしました」と説明する。

### 1:30 日報

日付を選び、引き継ぎ事項を追記して保存。確認後に確定する。
「売上が追加されると古い下書きは確定できず、再集計が必要になります」と説明する。

### 2:10 設計と次の改善

コードの該当箇所を指しながら、SQL集計・トランザクション・バージョン確認のうち説明できるものを一つ取り上げる。
「現在は1店舗のローカルデモです。次はヒアリングして取消・権限・通知を改善したいです」と終える。
